RESPONSIBLE USE

Only save media you can legally download.

Use NeonFetch X for your own files, public-domain media, creator-provided downloads, or content for which you have explicit authorization.

Platform page URLs such as YouTube, Dailymotion, Vimeo and TikTok are not direct media files and are intentionally rejected. This build does not extract protected streams or circumvent access controls.
FAQ / POLICY

Know the boundaries.

What kind of URL works?

A direct HTTP or HTTPS URL ending in a supported media extension such as .mp4, .webm, .mov, .mp3, .wav, .jpg or .png.

Why does a normal video-platform page fail?

A platform webpage is not the direct media file. NeonFetch X intentionally avoids stream extraction, DRM circumvention and platform-protection bypasses.

Why might the file open instead of downloading?

The remote server controls its response headers. For cross-origin resources, browsers may ignore the HTML download hint and open the media instead.
