RESPONSIBLE USE

Only save media you can legally download.

Use NeonFetch X for your own files, public-domain media, creator-provided downloads, or content for which you have explicit authorization.

Platform page URLs such as YouTube, Dailymotion, Vimeo and TikTok are intentionally rejected. This build does not extract protected streams or circumvent access controls.
FAQ / POLICY

Know the boundaries.

What kind of URL works?

A direct HTTP or HTTPS media URL whose server returns a supported video, audio, image, or generic binary content type.

Why does a normal video-platform page fail?

A platform webpage is not the direct media file. NeonFetch X intentionally avoids stream extraction, DRM circumvention and platform-protection bypasses.

Where is the file stored?

The app is designed to stream eligible files to the browser and does not intentionally keep permanent downloaded copies on the Render service.
